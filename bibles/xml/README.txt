Church Presenter — XML Bible Importer Folder
=============================================
Place your XML Twi Bible file(s) in this folder (e.g. twi.xml, twi_bible.xml).

Supported XML formats:
- Zefania XML (<XMLBIBLE>, <BIBLEBOOK>, <CHAPTER>, <VERS>)
- OSIS XML (<osisText>, <div type="book">, <chapter>, <verse>)
- USFX XML (<usfx>, <book>, <c>, <v>)
- Generic XML (<bible>, <book>, <chapter>, <verse>)

Once placed in this folder, Church Presenter will automatically scan and import your XML Twi Bible when launched!
